========================================
ENDPOINTS API REST
========================================

GET    /api/listar-viajes     → ListarViajesServlet  → ListarViajesDAO  → SELECT * FROM viajes
POST   /api/crear-viaje       → CrearViajeServlet    → CrearViajeDAO    → INSERT INTO viajes
PUT    /api/modificar-viaje   → ModificarViajeServlet → ModificarViajeDAO → UPDATE viajes
DELETE /api/eliminar-viaje    → EliminarViajeServlet → EliminarViajeDAO → DELETE FROM viajes

========================================
FLUJO DE DATOS (Ejemplo: Crear Viaje)
========================================

1. Usuario rellena formulario en index.html
2. JavaScript captura submit → preventDefault()
3. fetch('/api/crear-viaje', { method: 'POST', body: JSON.stringify(datos) })
4. CrearViajeServlet recibe la petición
5. Deserializa JSON con Gson
6. Crea objeto Viaje y llama a CrearViajeDAO
7. CrearViajeDAO ejecuta INSERT en MySQL
8. Retorna ID generado
9. CrearViajeServlet serializa respuesta JSON
10. JavaScript recibe respuesta en .then()
11. Si ok=true, recarga lista de viajes
12. Si error, lo captura en .catch() y muestra mensaje
